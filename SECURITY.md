# Security Policy

## Supported Versions

This package is still pre 1.0, so only the latest release receives security
updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately via [GitHub Security Advisories](https://github.com/fylgja/css-attr-polyfill/security/advisories/new).

We'll acknowledge your report as soon as possible and keep you updated as the issue is investigated and resolved. Once a fix is released, we'll credit you in the advisory unless you prefer to remain anonymous.
